# k10s brand assets

The k10s identity: a lime crab and custom lettering. Every file is plain vector paths: no fonts, no embedded bitmaps. Change the color through the `fill` attribute, and keep the proportions when scaling.

| File | What it is |
| --- | --- |
| `k10s-crab.svg` | The mark alone: lime on a transparent background. |
| `k10s-wordmark.svg` | The lettering, graphite, for light backgrounds. |
| `k10s-wordmark-light.svg` | The lettering, ivory, for dark backgrounds. |
| `k10s-lockup.svg` | Mark and lettering, for light backgrounds. |
| `k10s-lockup-light.svg` | Mark and lettering, for dark backgrounds. |
| `k10s-app-icon.svg` | The square app icon: lime on graphite. The app's icons in `crates/k10s-app/icons` are made from it (`npm --prefix ui run tauri icon branding/k10s-app-icon.svg`, from the repository root). |

## Colors

| Name | Hex |
| --- | --- |
| Lime | `#B7E64B` |
| Graphite | `#222722` |
| Ivory | `#F6F7EE` |
